# Registro de decisões arquiteturais

Criar um ADR quando houver uma escolha técnica com alternativas e consequências relevantes. Não usar ADR como substituto da aprovação de regra de negócio.

Formato: `ADR-NNN-titulo.md`, com estado, data, responsáveis, contexto, decisão, alternativas, consequências, regras relacionadas e condição de revisão. Estado: proposta, provisória, aceita ou substituída.

Ainda não há ADR técnico aceito. Stack .NET/React é direcionamento do produto; versões, autenticação, banco e implantação aguardam refinamento.
