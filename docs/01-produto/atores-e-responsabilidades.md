# Atores e responsabilidades

Catálogo candidato para refinamento. Não representa cargos oficiais nem concede permissões.

Públicos confirmados pelo solicitante: colaboradores internos, assessorias/parceiros externos e devedores. Essa confirmação não concede acesso comum entre os públicos.

| Ator candidato | Responsabilidade a validar |
|---|---|
| Colaborador interno | Operar funcionalidades dentro de seu escopo |
| Usuário externo/parceiro | Operar somente os dados e ações atribuídos ao vínculo externo |
| Devedor | Acessar jornadas próprias; recursos, titularidade e operações permitidas ainda precisam ser definidos |
| Administrador de usuários | Administrar ciclo de vida e atribuições dentro de limites delegados |
| Administrador de segurança | Administrar perfis, permissões e políticas de acesso |
| Gestor operacional | Administrar vínculos e responsabilidades operacionais autorizadas |
| Operador de Workflow | Consultar e executar ações autorizadas no processo |
| Auditor | Consultar evidências e histórico conforme autorização |
| Identidade técnica | Executar integrações e rotinas, se necessária |

Pendências: identidades técnicas, separação entre administração e aprovação, quem concede privilégios administrativos, acesso emergencial e responsável inicial pelo ambiente. Não criar um administrador irrestrito implicitamente.

Escopos confirmados: há usuários com atuação ampla, usuários restritos a um escritório e usuários vinculados a vários escritórios. Um escritório pode acessar várias carteiras. “Atuar em tudo” ainda não define poderes administrativos nem acesso aos dados de todos os países/empresas.
