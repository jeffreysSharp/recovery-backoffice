# Glossário inicial

Definições de trabalho; a semântica corporativa deve ser validada.

| Termo | Definição de trabalho | Estado |
|---|---|---|
| Usuário | Identidade de uma pessoa que acessa a plataforma; conta técnica ou genérica requer política específica | Proposta |
| Grupo | Agrupamento de usuários usado na administração de acesso | Relatado no legado; cardinalidade pendente |
| Hierarquia | Relação entre grupos; não implica herança automática de permissões | Semântica pendente |
| Perfil | Conjunto administrável de permissões | Proposta baseada no legado |
| Permissão | Autorização para uma ação em um recurso | Proposta |
| Objeto de segurança | Identificador legado de funcionalidade protegida | Relatado no legado |
| Escopo | Conjunto de dados sobre os quais uma ação pode ser autorizada | Proposta |
| Carteira | Agrupamento de créditos/casos referenciado pelo legado | Estrutura e propriedade a validar |
| Agência/assessoria | Entidade ligada à operação e às carteiras | Equivalência dos termos a validar |
| País | Dimensão geográfica de acesso | Relação com dados e organizações a validar |
| Papel pessoal | Rol_P no Workflow legado, associado ao usuário | Relatado no legado |
| Papel funcional | Rol_F no Workflow legado, associado a sistema e papéis pessoais | Relatado no legado |
| Responsável | Atribuição operacional em casos ou papéis de Workflow | Regras e exclusividade a validar |
| Revogação | Retirada efetiva de acesso, inclusive em sessões existentes | Proposta |

Grupo, perfil, papel de Workflow e escopo são conceitos distintos. A relação entre eles será explícita no modelo novo.
